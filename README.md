

\# Tamil Nadu Government Schemes AI Assistant



\## Project Overview

A bilingual AI-powered assistant designed to answer questions about Tamil Nadu Government Agriculture, Farmers Welfare and MSME schemes.



\## Languages

\- English

\- Tamil



\## Technology Stack

\- Python

\- Neo4j AuraDB

\- LangChain

\- GraphRAG

\- NVIDIA NeMo Guardrails

\- FastAPI

\- Streamlit

\- OpenAI API



\## Architecture

Government Data → Data Processing → Neo4j Knowledge Graph → LangChain GraphRAG → NeMo Guardrails → FastAPI → Streamlit
